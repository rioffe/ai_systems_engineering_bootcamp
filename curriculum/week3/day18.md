## Day 18 — Agentic development loops

Learn:

```text
SPEC
 ↓
PLAN
 ↓
IMPLEMENT
 ↓
TEST
 ↓
VERIFY
 ↓
FIX
 ↓
RETEST
```

Then build an autonomous loop.

The key concept:

> **Don't make the model smarter. Make the feedback loop better.**

Examples of verifiers:

* compiler
* unit tests
* static analyzer
* benchmark
* evaluator
* simulator
* type checker
* browser test
* security scanner
