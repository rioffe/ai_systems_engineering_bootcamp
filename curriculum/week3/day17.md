## Day 17 — Agent context management

This is one of the most important emerging skills.

Study:

* context budgeting
* context selection
* context compression
* summaries
* state
* scratchpads
* repository maps
* documentation
* task decomposition

Experiment:

Give the agent:

* entire repository
* relevant files only
* architecture summary
* tests
* explicit constraints

Measure performance.

You will see why **context engineering is becoming a software-engineering discipline.**
