## Day 20 — Coding-agent safety

Give your agent increasingly dangerous capabilities.

Examples:

* filesystem
* shell
* network
* database
* cloud deployment

Learn:

* sandboxing
* permissions
* allowlists
* human approval
* rollback
* transaction boundaries
* secrets isolation

Exercise:

Design an agent that **cannot destroy production** even if the model behaves maliciously or incorrectly.
